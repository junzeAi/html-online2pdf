# 钧泽Ai教育 - HTML 编辑器

一个纯前端的 HTML 可视化编辑器，支持代码/可视化双模式编辑，所见即所得地预览并导出为 A4 打印稿或 PDF。
专为试题试卷、讲义、知识点总结等需要精确 CSS 排版的教学场景设计。

无后端、无构建工具、无 npm 依赖。

## 快速开始

```bat
start-server.bat          # 等价于 python -m http.server 8080
```

浏览器访问 <http://localhost:8080>。

> ⚠️ **必须通过本地服务器访问**，不要直接双击打开 `index.html`。
> Monaco 编辑器依赖 AMD loader 以 HTTP 方式加载，`file://` 协议下会加载失败。

> 💡 **首屏为什么很快？** 打开时**不加载 Monaco**，直接进入可视化模式，
> 首屏只有约 190 KB（11 个请求）。只有点「代码模式」时才按需加载 Monaco（3.4MB），
> 加载期间编辑面板显示进度，失败可重试，且不影响可视化模式。
> 详见 [docs/DEPLOY.md](docs/DEPLOY.md)。

## 两种编辑模式

### 可视化模式（默认）

隐藏编辑器，直接在渲染结果上编辑（`contentEditable`）。
停止输入 300ms 后自动同步回源码。**打开页面即进入此模式，无需等待任何大文件。**

### 代码模式

左侧 Monaco 编辑 HTML 源码，右侧 iframe 实时预览。停止输入 300ms 后自动刷新。
在预览中选中文字，会自动定位并高亮编辑器中的对应位置。

> Monaco 是**按需加载**的：首次点击「代码模式」时才下载（约 3.4MB，之后浏览器缓存）。
> 加载期间编辑面板会显示进度；若加载失败会显示明确错误和「重试」按钮，
> 此时可视化模式完全不受影响。

- 点选任意元素：高亮框 + 浮动小工具条（删除 / 复制 / 上移 / 下移）
- 右侧属性面板：字体、字号、字重、文字色、行高、背景色/背景图、内外边距、
  边框（颜色/宽度/样式/圆角）、对齐、宽度，可一键清除所有内联样式
- 撤销/恢复上限 30 步（`Ctrl+Z` / `Ctrl+Y`）

## 导出

点击「导出」按钮选择格式：

- **导出 PDF** — 调起浏览器打印窗口，目标选「另存为 PDF」即可。
  **文件名会自动填好**（取自文档 `<title>`），不用手动改。
  首次使用请在打印窗口展开「更多设置」勾选**「背景图形」**，否则荧光笔等背景效果
  不会显示 —— Chrome 会记住这个设置，之后不用再勾。
- **导出 HTML** — 下载单文件 HTML 成品（已自动剔除编辑器内部样式）。

导出文件名取自文档 `<title>`，会自动清洗 Windows 非法字符与设备保留名（`CON`/`PRN` 等）。

> **为什么还需要点一下「保存」？**
> 浏览器出于安全考虑，不允许网页脚本静默生成并下载 PDF —— 任何网站若能偷偷
> 往你磁盘写文件都是灾难。所以「保留 100% 打印级样式」和「完全一键下载」二者
> 不可兼得，本项目选择前者：走浏览器自己的打印引擎，样式与打印预览完全一致。
> 若改用 html2canvas 之类的方案，产出的是**位图**，文字不可选中、分页容易截断。


## 技术栈

- 纯 HTML / CSS / JavaScript，无构建工具、无后端依赖
- [Monaco Editor](https://microsoft.github.io/monaco-editor/)（已本地化至 `lib/monaco/vs/`，不依赖 CDN；
  **按需加载**，只在进入代码模式时载入）
- 原生 iframe + `document.execCommand` 实现富文本编辑
- 浏览器原生打印实现 PDF 导出

## 注意事项

- PDF 导出依赖浏览器打印功能，在打印窗口中选择「另存为 PDF」；文件名会自动填好
- 导出时会自动声明 `@page { size: A4; margin: 0 }`。**这一步是必须的** ——
  不声明时 Chrome 会按屏幕尺寸缩放整页，而缩放会导致选区位置错位（选中的文字对不上）
  和插入光标异常变大。声明后缩放保持 100%，上述现象消失。
  代价是**页面留白完全由文档自身的内边距提供**，所以文档里请保留一定 padding，
  否则内容可能贴到纸边被打印机裁掉
- 荧光笔等背景效果基于 CSS 实现，导出 PDF 时需勾选「背景图形」（首次设置后浏览器会记住）
- 编辑器内容保存在浏览器 localStorage 中，换浏览器或清理缓存后会丢失，重要文件请用「导出 HTML」留存
- 推荐使用最新版 Chrome、Edge 或 Firefox
