# HTML预览编辑器 + PDF导出 设计文档

## 概述

一个纯前端的HTML代码编辑器，支持实时预览和高质量PDF导出。专为试题试卷、文章等需要精确CSS样式渲染的场景设计。

## 核心需求

- 编辑HTML代码（包含内嵌CSS样式）
- 实时预览渲染效果
- 导出PDF时保留所有CSS样式
- 支持A4标准打印格式

## 功能架构

### 模块划分

1. **代码编辑区** - 左侧，Monaco Editor，支持HTML/CSS语法高亮
2. **预览区** - 右侧，iframe实时渲染HTML内容
3. **工具栏** - 顶部，导出按钮和打印配置
4. **同步机制** - 防抖更新预览

### 数据流

```
用户编辑代码 → 防抖更新(300ms) → iframe预览刷新 → 点击导出 → 浏览器打印对话框
```

## 技术方案

### 技术栈

- 纯HTML + CSS + JavaScript
- Monaco Editor（CDN引入）
- 无构建工具，无后端依赖

### 关键实现

#### 1. 预览隔离

使用 `<iframe>` 渲染用户HTML，避免CSS污染主页面：

```javascript
iframe.srcdoc = userHtmlContent;
```

#### 2. 打印样式注入

在用户HTML中自动注入 `@media print` 样式，控制打印效果：

```css
@media print {
  @page {
    size: A4;
    margin: 用户选择的边距;
  }
  /* 防止分页断开 */
  .no-break { page-break-inside: avoid; }
}
```

#### 3. 防抖更新

```javascript
editor.onDidChangeModelContent(() => {
  clearTimeout(debounceTimer);
  debounceTimer = setTimeout(updatePreview, 300);
});
```

#### 4. 打印配置

- **边距选项**：无、窄(1cm)、中(2cm)、宽(3cm)
- **方向**：纵向、横向
- **纸张**：固定A4 (210mm × 297mm)

### PDF导出流程

```
点击导出PDF → 注入打印样式到iframe → 调用iframe.contentWindow.print() 
→ 浏览器打印对话框 → 用户选择"另存为PDF"
```

## 边界与限制

1. **CSS支持**：依赖浏览器原生渲染，支持所有CSS属性
2. **PDF生成**：依赖浏览器打印功能，用户需手动选择"另存为PDF"
3. **文件大小**：无限制，但大文件预览可能有性能延迟
4. **浏览器兼容**：推荐Chrome/Edge/Firefox最新版本

## 成功标准

- 编辑代码后预览实时更新，延迟不超过500ms
- 导出PDF保留所有CSS样式（字体、颜色、布局、边框等）
- A4纸张格式正确，边距配置生效
